Where the captured word gets sent. Use {TEXT} as a placeholder — it'll be replaced with the transcribed word (URL-encoded) before opening.

Example: myshowapp://reveal?word={TEXT}

Save your destination here first, then point the automation's "Open URLs" action at the plain page URL (no ?dest=) — Safari can refresh/reuse that tab without a query string surviving, so the setting needs to already be saved here rather than carried in the link.
